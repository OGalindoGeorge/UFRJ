Sensores de Temperatura

e Automação (UFRJ)

Igor Victorino de Carvalho

Resumo do Trabalho: 
O trabalho tem como objetivo mapear, dentro da linha de produção de uma empresa, 
através do uso de diversos sensores de mesma categoria, a temperatura.

Com o uso do simulador online TinkerCAD, foi possível elaborar e testar o protótipo
de leitura, assim como o código. Este foi escrito utilizando a ferramenta VSCode

O Problema: 
Nos foi proposto realizar a leitura de entrada de vários sensores de temperatura, estes que
estão instalados ao longo de uma linha de produção de uma empresa. A partir disso, coletar estes dados
e, de forma eficiente, catalogá-los em listas ordenadas que sejam de fácil e rápidos leitura e escrita.
